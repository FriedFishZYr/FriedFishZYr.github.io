    How AI feedback helps a calculus learner revisit a mistake

    The system generates narrated, interactive feedback before the lesson. A reasoning model writes a structured spec for each anticipated wrong answer, one template renders it, and only small model calls run while a learner waits.

  • Data mining and learning science researchAugust 2026 to present

    What 492 feedback episodes reveal about a learner’s next attempt

    I rebuilt 492 feedback episodes from raw interaction logs and modeled what each learner did next. A full-credit answer to the feedback’s own question went with a 30-point higher chance of fixing the original problem, and 32 cases show where that signal breaks.
